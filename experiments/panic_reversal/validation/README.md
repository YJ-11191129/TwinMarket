这些数字用于检查框架的机制依赖性。默认设定没有支持“流动性冲击后买跌必然获利”；羊群情景在移除估值交易项后发生变号，说明结果明显依赖结构选择。放慢恢复不会影响冲击后前几步的相同压力路径，部分远期影响也很小：当前现金流冲击和保证金收紧可能已较快完成清算，不能据此认定真实市场恢复速度无关。信息情景的基本价值永久下降仍可伴随情绪性超调，模拟不自动复现文献中的漂移/反转排序。

`sensitivity_summary.csv` 保存全部设定、机制、对照、持有期和成本的固定时点均值及跨种子 Monte Carlo 区间；`conditional_summary_default.csv` 保存默认矩阵的阶段/分歧分组结果；`paired_effects_default.csv` 保存同种子基准减对照的差值。阶段和分歧属于处理后变量，组间比较含成员变化，不能等同于干预因果效应。
